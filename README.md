## 👋 The Short Version

I spent years as a **lead dev** shipping React Native apps for **Walmart, Whataburger, Wayfair, Kwik Trip & more** — and got tired of debugging mobile apps with `console.log` and prayer.

So I built **[Buoy](https://buoy.gg)**: a full debugging platform for React Native. Not a tool. A **platform**.

- 🧰 **20+ devtools** living inside your app behind one draggable floating menu — network, storage, state, routes, renders, performance, and more
- 📦 **30+ packages** in a single monorepo powering it all, published under [`@buoy-gg`](https://www.npmjs.com/package/@buoy-gg/core)
- 🖥️ **Buoy Desktop** — a native external dashboard (macOS · Windows · Linux) that mirrors every tool over a live sync protocol
- 🤖 **An MCP server** so AI agents like Claude and Cursor can *drive the tools themselves* — read network traffic, inspect state, tap elements, run benchmarks, and fix your bugs on a real device
- 📺 Runs everywhere React runs: **iOS, Android, Web, Expo, RN CLI, tvOS, Android TV**
- ⚙️ **Zero config.** Install, drop in one component, done.

> Debugging tools shouldn't be an afterthought. They should be the reason you find the bug in minutes instead of days.

### 🤖 AI-Native Debugging (MCP)

> This is the part I'm most proud of. Buoy ships an **MCP server**, which means AI coding agents don't just read your code — they operate your running app. Claude can pull the actual failed request, inspect the actual store, tap through the actual screen, and verify the fix **on the device**.

```
You:    "why is the cart total wrong?"
Agent:  → reads live network responses off your phone
        → diffs the Zustand store against the API payload
        → finds the stale persisted value
        → fixes it, reloads, re-drives the screen, proves it
```

No more copy-pasting logs into a chat window. The agent has hands.
